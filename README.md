# Ethos Clan

A RuneLite plugin for the Ethos clan.

## Planned features

1. Drop and loot logging to a Discord webhook (opt-in)
2. Clan events: Skill/Boss of the Week from Wise Old Man, bingo tracking
3. Rank and attendance tracking, clan chat tools

## Running locally

```
./gradlew run
```

This starts a RuneLite development client with the plugin loaded. To log in with a Jagex account, follow
[Using Jagex Accounts](https://github.com/runelite/runelite/wiki/Using-Jagex-Accounts).
